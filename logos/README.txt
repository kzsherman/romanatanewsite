ROMANATA — partner logos
========================

Drop the logo image files in THIS folder using exactly these names, and they
will appear automatically in the "Our clients and partners" section on the
home page. Until a file exists, the site shows a lettered badge instead —
nothing breaks, and no broken-image icon is shown.

  consulate-netherlands.png   Consulate of the Kingdom of the Netherlands
  samsung.png                 Samsung
  toyota-center.png           Toyota Center
  globalink.png               Globalink
  icbc-bank.png               ICBC Bank
  altyn-bank.png              Altyn Bank

Notes
-----
* PNG with a transparent background works best. SVG also works — if you use
  SVG, change the file extension in index.html (search for "logos/").
* Roughly square images look best. Anything from 200x200 px upwards is fine;
  the logo is displayed inside a 48x48 px rounded tile and scaled to fit.
* Logos sit on a light (paper) background, so dark or full-colour logos read
  better than white-on-transparent ones.
* Use logos only with the owner's permission.
